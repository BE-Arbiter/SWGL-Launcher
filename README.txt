SWGL Launcher - Star Wars: Galactic Legacy
===========================================

The launcher installs the Galactic Legacy mod, keeps it up to date and
starts the game.


REQUIREMENTS
------------
- Windows 10 or 11, 64-bit.
- Star Wars Jedi Knight: Jedi Academy installed (Steam or any other version).


INSTALLATION
------------
1. Download SWGLLauncher.zip
2. Extract it into the game's GameData folder, next to jasp.exe.
   Steam example:
   ...\steamapps\common\Jedi Academy\GameData\
3. Run SWGLLauncher.exe.
4. Click "Update": the mod is downloaded and installed.
5. Click "Start" to play.

The launcher updates itself automatically when it starts.


USING THE LAUNCHER
------------------
Update   Installs, updates or repairs the mod. Only missing or changed
         files are downloaded, and an interrupted download resumes where
         it stopped. While it runs, the button becomes "Cancel".
Start    Starts the game.

Speaker button (title bar)
         Mutes or unmutes the music. The choice is remembered.
>>       Opens the log: every step, download and error. It also opens by
         itself when something goes wrong.
Patch notes
         Link shown next to the version when release notes are available.


OPTIONS MENU
------------
Configure Jedi Outcast...
         Imports the Jedi Outcast files needed by the missions taken from
         that game. Just point it to your Jedi Outcast install folder.
Configure Steam launcher...
         Adds the launcher to your Steam library, with its artwork. The
         launcher offers to restart Steam so it shows up.
Check integrity
         Checks every file of the mod and reports damaged ones, without
         downloading anything. Click "Update" afterwards to fix them.
Uninstall Galactic Legacy...
         Removes the mod (the SWGL folder and the mod's files). The
         launcher stays, so "Update" can install it again. Remove the
         Steam shortcut yourself if you added one.


TROUBLESHOOTING
---------------
- Open the log (>>) to see the exact error; the text can be copied.
- Run "Check integrity", then "Update".
- Make sure the launcher is in GameData, next to jasp.exe.


BETA (testers only)
-------------------
Beta access is reserved for testers who received a code.

- Options > Beta channel > Add beta code...: enter your code, then click
  "Update" to install the beta.
- Options > Beta channel > Public, then "Update": go back to the public
  release.
- Options > Beta channel > Remove this beta: forget the code.
